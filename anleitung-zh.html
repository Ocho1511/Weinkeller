1. 概览与入门

Weinkeller 是您装在口袋里的私人酒窖：您可以管理库存、存放位置、适饮期、心愿单和统计数据。一切都在您的设备上运行；通过同步码还可以连接多台设备。

底部（在电脑和横屏 iPad 上则在左侧）是包含八个板块的导航栏：

板块用途
酒窖所有葡萄酒、搜索、筛选、排序、添加葡萄酒、饮用
统计对库存、价格、适饮状态、存放情况和饮用历史的分析
适饮哪些酒现在、很快或已不宜饮用（“适饮期”）
历史您已经喝过的葡萄酒
酒架酒窖平面图：存放和移动葡萄酒、二维码标签
心愿单您还想购买的葡萄酒
导入导出备份数据，导入表格和备份文件
设置名称、货币、语言、云端、定义酒架

最初的五个步骤

  1. 选择语言和货币：设置 → 通用。货币会自动跟随语言。
  2. 定义酒架（可选）：设置 → 酒架（参见第 6 节）。
  3. 添加第一款葡萄酒：在酒窖中点按 +（第 2 节）。
  4. 存放：为这款酒在酒架上指定一个位置。
  5. 备份：导入导出 → JSON 备份，或设置云端同步（第 12 节）。
在设置中，各个部分都可以折叠。首次启动时“通用”处于展开状态，其他部分处于收起状态。应用会记住您上次展开或收起的内容。

2. 添加葡萄酒

在酒窖中点按 +。添加葡萄酒有多种方式，它们可以组合使用。

a) 手动输入

填写以下字段：名称 / 酒庄、年份、瓶数、葡萄酒类型、产区、国家、葡萄品种、存放位置、适饮起/适饮至、适饮温度、价格、评分、备注。只有名称是必填项。点按保存即可创建这款葡萄酒。

  • 适饮期：一旦输入年份，应用就会把“适饮起”设为年份 + 1。“适饮至”则取决于葡萄酒类型和葡萄品种（红葡萄酒比桃红保存得更久）。这两项您随时都可以修改。
  • 库存、最低和最高：如果您设置了最低库存，当库存低于该值时应用会提醒您，并提供将这款酒加入心愿单的选项（第 3 节）。
  • 自己的照片：“拍照 / 选择照片”可为葡萄酒附上一张照片。照片只保存在这台设备上，并包含在 JSON 备份中，但不会同步到云端。

b) 扫描酒标（AI）

点按扫描酒标（AI）并拍下酒瓶的酒标。AI 会识别名称、年份、类型、产区、国家和葡萄品种，并估算适饮期和适饮温度。请核对各项数值后保存。首次使用前，应用会征求您的同意（第 13 节）。

c) 扫描条形码

点按扫描条形码，将酒瓶的条形码对准取景框。应用会在免费的商品数据库中查询该号码（不收费，也不消耗 AI 额度），如果找到，就会自动填入名称、生产商和葡萄酒类型。年份会从名称中补全，或者向您询问。

  • 如果这瓶酒已经在酒窖里，应用会询问“再添加一瓶？”——买了更多时，这是快速累加数量的办法。
  • 如果条形码不在数据库中（小型酒庄很常见），会出现一条带有扫描酒标（AI）按钮的提示。这个号码仍会随这款酒一起保存，这样下次就能立刻识别这瓶酒。

d) 查询葡萄酒（AI）

查询葡萄酒（AI）会让 AI 在网上搜索产区、国家、葡萄品种、适饮期、适饮温度、当前平均价格，以及（在网页版中）酒瓶图片。您已经填写的字段不会被覆盖。当名称和年份已输入而价格尚未填写时，这一步也会自动执行。

iPhone 应用不会从互联网加载酒瓶图片（App Store 规定）。您可以改用自己拍摄的照片。

3. 酒窖

搜索、筛选、排序

  • 搜索（位于顶部）：可按名称、产区、国家和葡萄品种查找葡萄酒。
  • 筛选：全部、红葡萄酒、白葡萄酒、桃红、起泡酒、其他。点按某个类型时会自动清除搜索内容。
  • 排序：最新添加、名称、年份、葡萄品种、产区、国家，或适饮状态（最紧迫优先）。
  • 列表 / 卡片：点按列表按钮可在紧凑列表和详细卡片之间切换。

葡萄酒卡片

卡片会显示名称、年份、葡萄品种、评分（星级）、产区和国家（点按可打开地图或该国的葡萄酒产区）、瓶数、适饮温度（🌡）、存放位置（点按可跳转到酒架），以及一条适饮进度条，其颜色对应尚年轻、最佳、巅峰、已过期。点按葡萄图标会打开该葡萄品种的维基百科（Wikipedia）页面。

卡片底部有：编辑、饮用和 🗑（删除葡萄酒）。

库存、最低/最高与购物清单

如果您为某款葡萄酒设置了最低库存（也可以再设置最高库存），卡片会显示“库存 · 最低 · 最高”，库存低于最低值时会用 ⚠ 提醒。补货按钮会打开购物清单：其中列出所有低于最低库存的葡萄酒（目标数量为最高库存，没有设置时则为最低库存）。您可以分享或复制这份清单，也可以把这些酒加入心愿单。

4. 饮用葡萄酒

在葡萄酒卡片上点按饮用（或在适饮页面点按“饮用 · n 瓶”）。随后会打开饮用葡萄酒对话框：

  • 从哪个位置取出？——选择这瓶酒取自的酒架位置，或选择“酒瓶不在任何位置”。该位置随之变为空闲。
  • 和谁一起喝的？——您的客人姓名（可选）。
  • 场合——春天、夏天、秋天、冬天、生日、派对或“随心小酌”（可多选）。

饮用会减少一瓶，并在历史中新增一条记录。彩带和音效会为此庆祝（可在设置中关闭）。如果这是最后一瓶，应用会提示您：这款酒随后会从酒窖中消失（但仍保留在历史中）。

扫描快速饮用：酒窖中圆形的 🥂 按钮会拍下酒标，在您的酒窖中识别出这款酒，并立即打开饮用对话框。

5. 适饮期（适饮）

在这里，您可以看到所有设有适饮期的葡萄酒，最紧迫的排在最前。每张卡片会显示名称、年份、类型、适饮起/适饮至、适饮温度、存放位置，以及一条标有当前年份的进度条。

状态含义
尚年轻太早——还没到“适饮起”
最佳可以饮用，仍处于适饮期的前段
巅峰正值巅峰——请尽快饮用
已过期已过“适饮至”——请尽快饮用

筛选：按葡萄酒类型、按状态和按国家（下拉菜单中显示每个国家的数量；没有匹配结果的国家会显示为灰色）。这些筛选条件可以组合使用。点按卡片即可在酒窖中打开这款葡萄酒。

适饮期的规则：“适饮起”= 年份 + 1。“适饮至”取决于葡萄酒类型和葡萄品种。如果您有一些旧酒设置了其他数值，可以在设置中一次性重新计算全部（第 11 节，“重新计算适饮期”）。

6. 酒架与存放

定义和编辑酒架

设置 → 酒架（点按标题展开）：输入名称、层数、每层的位数和每位的瓶数，然后点按 ＋。“瓶/位”对于酒架是 1，对于地面堆放或酒箱则更大。在列表中，每个酒架都有：

  • 用于调整顺序的拖动手柄 ⠿，以及列表下方的按 A–Z 排序按钮，
  • ▦ 用于二维码标签，✏️ 用于编辑，🧹 用于清空，🗑 用于删除。

通过编辑（✏️），您可以重命名酒架、更改每层的位数、在上方或下方添加层、删除层，并为每一层设置独立的名称和瓶数。因此而失去位置的酒瓶之后会算作“未存放”；这些葡萄酒本身仍留在酒窖中。进行此类更改前，应用会先询问您。

酒架板块

在顶部，您可以通过图块选择酒架（显示名称和“已占用 / 位数”）。顺序也可以在这里调整：在电脑上拖动图块；在触摸屏上长按图块约半秒，然后拖动。下方是酒窖平面图：每一层及其各个位置。已占用的位置会显示一瓶平放的酒，颜色对应葡萄酒类型。

存放

  1. 点按“未分配”下的一款葡萄酒（该列表可按类型和国家筛选）——或者点按酒窖中的“未存放”提示。
  2. 点按一个空闲位置。对于地面堆放和酒箱，应用会存入尽可能多的酒瓶。

扫描葡萄酒并存放会拍下酒标，找到对应的葡萄酒，并引导您完成存放。

已占用的位置、移动、移除

点按一个已占用的位置：您会看到这款葡萄酒，并可以打开它、从位置移除，或移动它（然后点按一个空闲位置）。清空酒架会取出酒架上的所有酒瓶（需先确认）。

闪烁

通过闪烁开关，您可以让以下酒瓶闪烁：应优先饮用的（已过期，或最迟明年就到适饮期末尾的）、已过期的、处于巅峰的或处于最佳状态的——这样您在酒架上一眼就能找到它们。

二维码标签与“扫描层”

使用二维码标签（设置 → 酒架 → ▦），可以为酒架制作一张标签，并为每一层各制作一张。可分享为 PDF 或直接打印（标签纸 63.5 × 38.1 mm，每页 21 张），然后贴上。之后：在酒架板块中使用扫描层——您会看到该层存放了什么，并可以存放到这里、取出、饮用、移动某一瓶，或整层移动。在“添加葡萄酒”表单中，扫描层标签同样会自动填入存放位置。

7. 历史

历史会列出您喝过的所有葡萄酒，包括日期、葡萄酒、价值、客人和场合。您可以按葡萄酒类型和场合筛选，并编辑某条记录（客人、场合）。历史为统计中的“每月/每年饮用量”、支出和饮用频率提供数据。

8. 心愿单

  • + 添加心愿：手动输入或扫描酒标，还可附上备注（“在哪里买？”）。
  • 搜索价格（💶）：应用会在网上搜索这款葡萄酒的价格，显示最低的结果，并乘以数量。这些只是参考值，不作任何保证——请向商家确认运费和供货情况。
  • 勾选框（位于左侧）：标记为已购买/已完成（该行会变淡）。
  • → 酒窖：把这个心愿移入酒窖（带上数量，如有的话还有最低价格）；如果您已设置酒架，会直接带您去存放。
  • 如果某款葡萄酒低于其最低库存，应用会提议按缺少的数量把它加入心愿单（“补货”）。

9. 统计

从上到下依次为：

  • 关键数据：瓶数、款数、总价值、均分。
  • 适饮期：每种状态（尚年轻、最佳、巅峰、已过期）的瓶数，已过期的酒瓶会有警告；点按会打开适饮页面并应用对应的筛选。
  • 按类型和最佳葡萄酒（按评分或频率，可按星级筛选）。
  • 按国家、产区、品种：条形图（最多 8 项，其余显示为“另有 +n 项”）；点按会在酒窖中搜索。按年份：柱状图，可左右滚动。
  • 价格：每瓶平均价、最低价、最高价、价格区间（已匹配您的货币）以及按国家统计的价值。
  • 储存：占用率（百分比）、空闲位置、未存放的酒瓶，以及每个酒架一条的进度条（点按可跳转到该酒架）。
  • 已饮用：按月（最近 12 个月）和按年统计，以及已饮用酒瓶的花费。
  • 最佳国家和葡萄品种：按平均评分排列（酒窖与历史合并计算）。
  • 补货：低于最低库存的葡萄酒（会打开购物清单）、未完成的心愿及其价值。

没有数据的部分（例如没有价格时）会被隐藏。

11. 设置

通用

  • 显示名称（标题）：输入“Peter”，标题就会变成“Peter 的 Weinkeller”，依此类推。留空则使用默认标题。
  • 货币：€、$、£、CHF、A$、C$、SEK、NOK、DKK、PLN、HUF、CZK、RON、RUB、UAH、JPY、CNY、KRW、INR。
  • 语言：25 种语言版本，包括德语、英语、英语（美国）等众多语言。货币会自动随之变化（瑞典语 → 克朗，英语（美国）→ 美元，英语（英国）→ £）。例如：当您切换到瑞典语时，应用会改为 SEK，并询问是按今天的欧洲中央银行汇率换算所有价格（“确定”），还是只更改标签（“取消”）。RUB 和 UAH 没有汇率。您随时可以手动更改货币。
  • 饮用时的彩带与音效：两者都开、仅彩带，或关闭。
  • 字体：可从十种字体中选择。
  • 温度单位：°C 或 °F（英语（美国）会自动设为 °F）。

存储

仅限此设备或云端（同步码，第 12 节）。

AI 额度（仅限 iPhone 应用）

显示剩余的 AI 扫描次数、设备 ID，并在需要时显示充值额度或解锁码。参见第 13 节。

葡萄酒数据库

  • 更新所有葡萄酒（AI）：为所有葡萄酒补全缺失的产区、国家、葡萄品种、适饮期、适饮温度和价格（网页版还会补全酒瓶图片）。已有的数值保持不变。如果已经存在适饮温度，应用会先询问是否也要用 AI 的数值替换它们。
  • 重新计算适饮期：为所有有年份的葡萄酒把“适饮起”设为年份 + 1（手动输入的数值也会被覆盖），并在需要时调整“适饮至”。应用会先告知涉及的葡萄酒数量，并请您确认。小贴士：请先导出一份 JSON 备份。

酒架

参见第 6 节。标题处会显示酒架的数量。

隐私政策、支持与帮助、版本

这些链接会通向隐私政策和本支持页面。在最底部您可以看到应用的版本——联系我们时请告知该版本号。

12. 在两台设备间同步

  1. 第一台设备：设置 → 存储 → 云端 → 创建新的同步码。同步码会显示在屏幕上；使用通过邮件保存同步码可以把它发给自己。
  2. 第二台设备：设置 → 存储 → 云端 → 输入同步码（小写，不含空格）→ 连接。如果该设备上已有葡萄酒，应用会询问是否与云端数据合并。
  3. 此后两台设备会自动同步（例如在打开应用时）；立即同步可手动触发。规则是：以最新的更改为准。

葡萄酒、心愿单、历史、酒架以及语言和货币等设置都会同步。不会同步的是自己的照片和设备专属数据。任何知道您同步码的人都能看到您的葡萄酒——请只与您信任的人分享。同时也请保留一份 JSON 备份。

13. AI、隐私与费用

  • AI 用于什么？扫描酒标、查询葡萄酒、搜索价格和“更新所有葡萄酒”。照片或葡萄酒名称会通过我们的服务器发送给 AI 服务（Anthropic，美国）进行分析——不含姓名或账号。首次使用前，应用会征求您的同意。
  • 条形码扫描只会把号码发送到免费的商品数据库，不消耗 AI 额度。
  • 费用（iPhone 应用）：每次安装包含在购买价格内的 AI 调用次数为 50 次；更多次数可作为可选的一次性购买项目购买（无需订阅，额度不会过期）。应用中的其他一切都不额外收费。额度用完后，除 AI 功能外的所有功能仍可继续使用。
  • 数据：只要您不启用云端，所有内容都保存在您的设备上。没有广告，没有跟踪，没有用户账号。详情见隐私政策（德语）。

14. 小贴士与常见问题

  • 在 iPad 或电脑上，界面布局会自动适配：栏位更宽、多张卡片并排显示，在电脑（以及横屏的 iPad）上导航栏位于左侧。手机也可以横屏使用。在电脑上按 Esc 可关闭最上层的窗口；在手机上向下滑动窗口即可关闭。
  • 我的葡萄酒不见了：请参见支持——可通过同步码或 JSON 备份恢复。
