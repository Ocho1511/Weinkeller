Häufige Fragen

Meine Weine sind weg – was kann ich tun?

Deine Weine liegen lokal auf deinem Gerät. Wenn du die App gelöscht hast, sind sie weg, außer du hast den Cloud-Sync benutzt oder eine Sicherung exportiert. Mit Cloud-Sync: Setup → Speicherort → Cloud → „Mit Code verbinden" und den Sync-Code eingeben (Kleinbuchstaben, ohne Leerzeichen). Mit Sicherung: Export/Import → JSON importieren. Tipp: Exportiere ab und zu eine JSON-Sicherung.

Wie synchronisiere ich zwei Geräte?

Auf dem ersten Gerät: Setup → Speicherort → Cloud → „Neuen Code erzeugen". Den Code kannst du dir per E-Mail schicken. Auf dem zweiten Gerät: Cloud → Code eingeben → verbinden. Wer den Code kennt, kann deine Weine sehen; gib ihn nur an Personen weiter, denen du vertraust.

Wofür sind die KI-Scans und was kosten sie?

Etikett scannen und Wein nachschlagen nutzen eine KI. Die ersten 50 Aufrufe je Installation sind kostenlos, weitere Aufrufe gibt es (sobald verfügbar) als optionalen In-App-Kauf. Alles andere in der App ist kostenlos. Vor der ersten Nutzung fragt dich die App um Einwilligung, weil Foto bzw. Weinname zur Auswertung an einen KI-Dienst gesendet werden.

Ich habe Guthaben gekauft, aber es kommt nicht an

Öffne die App mit Internetverbindung und warte einen Moment; das Guthaben wird beim Einlösen des Kaufs gutgeschrieben. Hilft das nicht, schreib mir mit dem Kaufdatum (Apple-Beleg). Erstattungen bearbeitet Apple (reportaproblem.apple.com).

Kann ich meine Daten löschen lassen?

Ja. Lokale Daten verschwinden, wenn du die App löschst. Für Daten in der Cloud oder zum KI-Guthaben schreib mir bitte an die E-Mail-Adresse oben, mit deinem Sync-Code bzw. der Gerätekennung aus Setup → KI-Guthaben.

Wo finde ich die Datenschutzerklärung?

Datenschutzerklärung (auch in der App unter Setup).

English

My wines are gone. Your wines are stored on your device. If you deleted the app they are gone unless you used cloud sync or exported a backup. With cloud sync: Setup → Storage → Cloud → connect with your sync code (lowercase, no spaces). With a backup: Export/Import → import JSON. Tip: export a JSON backup from time to time.

AI scans. Label scan and wine lookup use an AI service. The first 50 calls per installation are free; more can be bought as an optional in-app purchase (when available). Everything else is free. The app asks for your consent before the first AI use.

Delete my data. Local data is removed when you delete the app. For cloud data or the AI credit record, email us with your sync code or the device ID from Setup → AI credits. See the privacy policy (German).
