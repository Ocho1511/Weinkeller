2. Worum es geht

„Weinkeller" ist eine App zur Verwaltung einer privaten Weinsammlung. Es gibt kein Tracking, keine Werbung, keine Analyse-Werkzeuge von Dritten und kein Benutzerkonto (keine Anmeldung, keine E-Mail-Adresse). Damit das KI-Guthaben abgerechnet und Missbrauch verhindert werden kann, speichert unser Server wenige anonyme Kennzahlen pro Installation (siehe Punkt 6).

3. Deine Weindaten

Deine Weine, Wunschliste, Trinkhistorie, Regalpläne und Einstellungen werden lokal auf deinem Gerät gespeichert. Wir haben darauf keinen Zugriff. Wenn du die App löschst, werden diese Daten gelöscht, sofern du die Cloud-Funktion nicht nutzt.

4. Optional: Cloud-Sync

Wenn du den Cloud-Speicher aktivierst, werden deine Weindaten (Weine, Wunschliste, Historie, Regale, Anzeigename) auf einem Server von Cloudflare, Inc. (Cloudflare Workers/KV) gespeichert. Der Zugriff erfolgt ausschließlich über einen zufälligen Sync-Code, den die App erzeugt; es werden keine Namen, E-Mail-Adressen oder Konten verlangt. Wer den Code kennt, kann auf diese Daten zugreifen – bewahre ihn daher sicher auf. Du kannst die Cloud jederzeit deaktivieren; auf Anfrage löschen wir die zu deinem Code gespeicherten Daten. Cloud-Sicherungen, die 400 Tage lang nicht geändert wurden, werden automatisch gelöscht.

5. KI-Funktionen (Etikett scannen, Wein nachschlagen)

Wenn du „Etikett scannen" oder „Wein nachschlagen" nutzt, wird das Foto des Etiketts bzw. der eingegebene Weinname über unseren Server (Cloudflare Worker) an Anthropic (Claude) zur Auswertung gesendet, um Weindaten zu erkennen und zu ergänzen. Das Ergebnis wird an die App zurückgegeben. Fotos werden von uns nicht gespeichert. Bevor du eine KI-Funktion zum ersten Mal nutzt, fragt dich die App um deine Einwilligung; ohne Einwilligung wird nichts gesendet. Anthropic verarbeitet die Daten nach den Bedingungen seiner Programmierschnittstelle. Bitte fotografiere keine Personen. Die Nutzung ist freiwillig.

6. KI-Guthaben und Installations-Kennung

Die KI-Funktionen sind mengenmäßig begrenzt: Die ersten 50 KI-Aufrufe je Installation sind kostenlos, weitere Aufrufe können (sobald angeboten) per In-App-Kauf erworben werden. Damit der Server das Guthaben zählen kann, erzeugt die App beim ersten Start eine zufällige Installations-Kennung (keine Verbindung zu deinem Namen, deiner Apple-ID oder deiner Telefonnummer) und sendet sie bei jedem KI-Aufruf mit. Der Server speichert zu dieser Kennung den Guthaben-Stand, die Zahl der KI-Aufrufe sowie Zeitpunkt der Erstellung und der letzten Nutzung (so lange das Guthaben-Konto besteht; auf Anfrage löschen wir es). Aus diesen Zahlen erstellen wir anonyme Gesamtübersichten, zum Beispiel wie viele Installationen es gibt. Zum Schutz vor Missbrauch wird die IP-Adresse in gekürzter Form höchstens zwei Tage lang für ein Limit neuer Installationen und für Fehlversuchszähler verarbeitet; sie wird nicht mit deinem Konto verknüpft. Gibst du einen Freischaltcode ein, wird davon nur ein Prüfwert (Hash) gespeichert. Rechtsgrundlage ist die Bereitstellung der von dir genutzten Funktion (Art. 6 Abs. 1 lit. b DSGVO) und unser berechtigtes Interesse am Schutz vor Missbrauch und Kostenkontrolle (lit. f).

6a. In-App-Käufe

Zusätzliches KI-Guthaben kann über den In-App-Kauf von Apple erworben werden. Die Zahlung wickelt ausschließlich Apple ab; wir erhalten keine Zahlungs- oder Kontodaten, sondern nur einen von Apple signierten Beleg. Zu jedem eingelösten Kauf speichern wir die Transaktionsnummer, das gekaufte Paket, den Zeitpunkt und die Installations-Kennung, damit ein Kauf nur einmal gutgeschrieben und bei einer Erstattung wieder abgezogen werden kann.

7. Flaschenbilder

Für Flaschenbilder wird der Weinname (ggf. mit Jahrgang, Rebsorte, Region) über unseren Server an Vivino abgefragt. Beim Anzeigen der Bilder lädt dein Gerät diese direkt von images.vivino.com; dabei wird technisch bedingt deine IP-Adresse an den Betreiber übertragen. Gibst du selbst eine Bild-Adresse ein oder findet die KI-Suche eine Bildquelle, lädt dein Gerät das Bild ebenfalls direkt vom jeweiligen Server; auch dorthin wird technisch bedingt deine IP-Adresse übertragen. Unser Server ruft dafür bei Bedarf die angegebene Webseite ab, um das Vorschaubild zu finden.

8. Kamera und Fotos

Die App fragt den Zugriff auf Kamera bzw. Fotomediathek nur an, wenn du ein Etikett oder einen Lagerplatz fotografieren möchtest. Die Aufnahmen werden nur für die jeweilige Erkennung verwendet (siehe Punkt 5).

9. Externe Links

Die Symbole „Region auf Karte" und „Wikipedia" öffnen externe Webseiten (Google Maps bzw. Wikipedia) in deinem Browser. Für deren Datenverarbeitung sind die jeweiligen Betreiber verantwortlich.
